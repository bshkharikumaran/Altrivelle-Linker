## Reporting a Vulnerability

Security is paramount to Altrivelle Linker. If you discover a security vulnerability or bypass:

1. **Do not create a public GitHub issue.**
2. Send a detailed report to security@altrivelletechnologies.com or submit a private security advisory through GitHub.
3. Include:
   - Nature of the issue (e.g. RLS bypass, XSS, token leakage)
   - Steps to reproduce
   - Potential impact
4. The security team at ALTRIVELLE TECHNOLOGIES will acknowledge your report within 48 hours and work on a prioritized remediation.
